# CKA Exam Practice - KillerCoda Environment

A KillerCoda scenario that pre-configures all **CKA exam prerequisites** so you can practice **only your exam tasks** clearly and repeatedly.

---

## Quick Start (Using KillerCoda)

### Option A: Use an Existing KillerCoda Scenario

If someone has published this scenario on KillerCoda:

1. Go to [killercoda.com](https://killercoda.com)
2. Search for **CKA Exam Practice** or use the direct link
3. Click **Start Scenario**
4. Wait for setup (~1–2 minutes)
5. Start practicing from the task list

### Option B: Publish Your Own Scenario

1. **Fork or create a GitHub repo** with this `killercoda-cka` folder
2. **Connect to KillerCoda**:
   - Go to [killercoda.com/creator/scenarios](https://killercoda.com/creator/scenarios)
   - Sign in → Add GitHub repository
   - Select the repo and branch
3. **Scenario path**: If the scenario is in a subfolder (e.g. `killercoda-cka`), set that in KillerCoda, or place `index.json` at the repo root
4. **Start the scenario** and wait for setup

### Option C: Run Manually in Any KillerCoda Kubernetes Environment

1. Start any **Kubernetes** scenario on KillerCoda (e.g. `kubernetes-kubeadm-2nodes`)
2. Clone or copy this repo, or run the setup script directly:
   ```bash
   curl -sL https://raw.githubusercontent.com/YOUR_REPO/main/killercoda-cka/scripts/setup-cka-prerequisites.sh | bash
   ```
3. Or copy the script contents and run locally

## Step-by-Step: Setup, Practice, Reset

### 1. First-Time Setup

When the scenario starts:

- **Background**: Creates namespaces, deployments, PVs, CRDs, etc. (what the exam already has)
- **Foreground**: Shows a summary and waits for the background to finish
- **Result**: `~/cka-practice-tasks.txt` is created with the full task list

### 2. Practice Your Tasks

Open the terminal and:

```bash
# View what to do
cat ~/cka-practice-tasks.txt
```

Then follow each question’s **YOUR TASK** section.

Example for Q1:

```bash
# Q1 - HPA
kubectl autoscale deployment apache-server -n auto-scale --cpu-percent=50 --min=1 --max=4
kubectl patch hpa apache-server -n auto-scale --type='merge' -p '{"spec":{"behavior":{"scaleDown":{"stabilizationWindowSeconds":30}}}}'
kubectl get hpa -n auto-scale
```

### 3. Practice Again (Reset)

When you want a clean state:

```bash
./scripts/reset-and-practice.sh
```

This will:

1. Remove what you created
2. Restore prerequisites
3. Re-run setup
4. Print the task list again

You can run it as often as you need.

├── intro.md                # Welcome / intro
├── foreground.sh           # Visible setup (waits for background)
├── background.sh           # Prerequisites setup (runs in background)
├── finish.md               # End message
├── README.md               # This file
├── scripts/
│   ├── setup-cka-prerequisites.sh   # Creates all exam prerequisites

│   ├── practice.md         # Practice instructions

## Troubleshooting

| Issue | Solution |
|------|----------|
| Setup takes too long | Check `/var/log/killercoda/cka-setup.log` |
| `helm` not found | Setup installs Helm; wait for background to finish |
| Script not found | Ensure `scripts/setup-cka-prerequisites.sh` exists and is executable |
| Reset fails | Run `./scripts/setup-cka-prerequisites.sh` to re-run setup only |
| Some resources fail | Some items (e.g. Gateway API) need network; retry or skip that part |
