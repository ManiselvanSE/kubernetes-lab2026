# Kubernetes Lab 2026 — CKA Study Hub

This repository collects Certified Kubernetes Administrator (CKA) preparation notes, quick references, practice questions, and a Killercoda-style practice environment.

## Recommended learning order

1. [Study guide](CKA_EXAM_STUDY_GUIDE.md) — use as the main syllabus and progress tracker.
2. [Quick reference](CKA_QUICK_REFERENCE.md) — commands and syntax for revision.
3. [Flashcards](CKA_FLASHCARDS.md) — short recall sessions.
4. [Complete hands-on exam guide](CKA_COMPLETE_HANDS_ON_EXAM_GUIDE.md) — longer practical walkthroughs.
5. [Question-by-question deep guide](CKA_DEEP_GUIDE_QUESTION_BY_QUESTION.md) — targeted practice and explanations.
6. [Exam prep complete guide](EXAM_PREP_COMPLETE_GUIDE.md) — consolidated preparation reference.
7. [Killercoda CKA practice](killercoda-cka/README.md) — interactive scenario setup.
8. [Practice exam setup](practice-exam-setup/README.md) — scripts for preparing practice tasks.

The file [CKA exam practice notes](CKA%20exam%20Practise_new%20(1).odt) is an additional source document; use the Markdown guides above for easier navigation and search.

## Suggested weekly routine

- **Learn:** review one topic from the study guide.
- **Practice:** perform the task from a clean terminal, without copying commands blindly.
- **Recall:** revise flashcards and quick-reference commands.
- **Simulate:** complete timed scenarios and verify the cluster state after each task.
- **Review:** record mistakes and repeat the weak areas.

## Safe use

- These materials are personal study notes, not official exam content. Confirm current exam scope and allowed resources with the official Kubernetes certification provider.
- Review scripts before running them, especially setup and cleanup scripts that create or delete cluster resources.
- Avoid committing kubeconfigs, tokens, cloud credentials, or other secrets.

## Repository maintenance

Keep one canonical explanation per topic and link to it from this index rather than duplicating long content across files.
